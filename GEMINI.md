# Agent Guidelines & Rules

- **Communication Language**: Always communicate with the user strictly in Hinglish (Hindi written in Latin script, e.g. "Maine code update kar diya hai..."). Never reply in pure Hindi (Devanagari script) or pure formal English unless explicitly requested by the user.
- **Code Comments**: Never add comments (inline comments, block comments, docstrings, or explanatory notes) inside any code files. Keep all code completely clean and free of comments.
